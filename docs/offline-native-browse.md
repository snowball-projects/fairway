# Local native browse and reserved transport review

The existing fairway interface now reads native facility/course transport DTOs
through an injected deterministic adapter. It has no static catalog fallback,
JSON authority, browser SQLite, live endpoint or new service. The published site,
private national API, admission fix, provider bridge, catalog and frozen reviews
remain unchanged. The selected worktree is a local source prototype.

The original frontend loaded a static public facility snapshot and called a
Chicago ranking API after Photon address resolution. The private national API
accepts a bounded national request and returns a final response; its Origin
rejection and trusted caller boundary are unchanged. Neither interface implements
these proposed paged catalog/preparation paths. The distinct modo area stage is
retained in the local progressive display rather than replaced with catalog-first
optimization. Original UI and timing findings are in plan-a-round-progressive.md;
its old routing mock/cache is historical and is not the current transport.

## Native browse

The pinned revision21 examples from catalog source af27fe88298f83ce0f78eed2a3139777bec9764d
provide two selected facilities and three Corica course records. They are read-only
query examples, not a complete national snapshot. Course fixture-only commit4cf4497
changes no module/schema bytes. Provenance is in tests/fixtures/catalog-native/.
No fixture metadata is rewritten or applied as catalog authority.

The selected native example window has two map identities. Corica's three stable
course IDs share one qualified facility destination; all canonical arrivals stay
null. Cog Hill's 72 physical holes and empty stored inventory remain a facility
context without synthetic course cards. Nullable names retain facility headings
and an honest qualifier. Retained needs_review identities remain visible and are
not certified independent bookable courses.

Browse includes all access. Plan uses the supplied plan_eligible and original
qualification, separately from nullable actual nonmember_bookable. No facility
access promotes a component. Search and Search this area perform local selection
only, show no driving times and dispatch no routing. Input typing performs no
address resolution/routing. Enter or blur resolves only a supplied literal test
address or a valid coordinate. This prototype has no external address fallback
or basemap requests. Initial native catalog loading is safe preparatory work.

State, physical course holes, documented round holes, native style and recorded
price-information filters are distinct. A nine-hole course participating in a
recorded eighteen-hole combination keeps its physical length and course ID.
Facility totals never become layout filters. Typed styles are Regulation,
Executive, Par3, Pitch & Putt and grass Putting; explicit obstacle miniature golf
stays distinct. No style/access/booking fact is classified from names or notes.
Practice-green/surface taxonomy still requires an agreed typed catalog field.

Optional price details whitelist numeric fields and preserve currency, basis,
source URL, scope, observed/collected/source-information dates, status, conditions,
historical/current qualification and conflicts. Missing/unrecognized stays
unknown. Current comparable price sorting is deferred: existing historical ranges
are not scalar current visitor fees. A tested helper permits only an explicitly
current, unconditional course-scoped scalar with matching currency/basis and no
conflicting latest observation; it is not a user-facing current-price promise.
Amenity absence stays unknown. Quality ratings/publisher badges remain deferred;
tee difficulty is not a quality score.

## Reserved offline transport

private-transport.mjs requires an injected fake fetcher, explicit offline mode and
fake caller authorization. It never defaults to window.fetch, removes fixtureOnly
or changes the national API. These are review guards, not implemented server
authentication. Authentication and session ownership must be enforced by a future
trusted ingress; opaque IDs are only locators. No credentials are included.

The accepted path proposal is copied byte-for-byte in private-transport-contract.md.
Catalog reads bind revision across all pages and both native resource types.
Preparation reads bind request_key, ordered origins, generation, catalog revision
and immutable snapshot_sequence. Summary/row, shared-target, area, page and score
checks retain the independently reviewed DTO correction. Short/mixed reads fail
atomically. Catalog, cursor and snapshot conflicts restart reads only, at most
three attempts; they never POST again. Local read bounds are 64 pages of at most
1000 rows, 256 event polls, 4MiB per response and 250..15000ms poll delays. These are
proposed client bounds, not a deployed session retention guarantee.

Transport-only fake snapshots add required preparation_limited and
area_search_complete booleans. The frozen e8 fixture bytes remain unchanged.
Finite limits retain the whole pool and complete integer-origin vectors as
qualified provisional scores. Pending vectors remain score-null. A new test-only
status seam demonstrates a visible warning and independent incomplete area status.
Fatal failures revoke provisional scores and origin times; uncertain outcomes
never grant replacement admission. An explicit engine_unknown=false is required,
as well as operation_started=false, busy/rate status and bounded Retry-After,
before exposing an explicit retry. No automatic retry is implemented.

The UI still consumes the separately frozen e8 synthetic preparation fixture.
Its synthetic revision0 courses/areas/times and revision21 native browse examples
are explicitly separate demonstration scopes. They are not asserted to be a
single live joined catalog/planning session. The private transport preparation
consumer is fake-fetch tested and has no browser/server binding. Local fixture
completion only releases its local replay slot; native_admission_released remains
false. Sorting both max and sum from completed vectors does not equate separate
objective-specific modo area searches. Actively interacted rows keep their order.

All real routing phases must share the API bridge's32 dispatch/4096 cell/256 point/
30 second operation envelope, including modo work.24 is a provisional routing
window, never a pool/display cap. The bridge has no automatic continuation or
budget-resetting POST; the frontend does not add one. Larger final pools may stay
partially unscored. The frozen bridge source d96714a remains pinned to reviewed
b047 schema1..3; af27 modules plus001..004 require a separately reviewed dependency
upgrade before real native catalog reads.

## Timing and remaining blockers

Use monotonic stage spans: committed origin resolution; first local course paint;
modo admission delay, modo area compute and area-visible delay; fairway matrix
batch duration/cell count; fairway scoring; full-pool final-rank paint. Overlapping
spans are not added blindly and clocks from different processes are not subtracted.
Router times arrive as matrix batches, not guaranteed individual-cell streaming.
No final comparable course score exists without all required origin times;
missing/unreachable never becomes zero. The requested5..10 seconds remains a
performance target, not an observed provider result. Browser checks use a virtual
clock, supplied40ms resolution and synthetic400/800ms replay waits only.

Live cutover remains pending, not denied: trusted browser caller/origin authorization,
server-owned session retention/ownership, immutable snapshot assembly, pinned
schema4 dependency integration, reviewed terminal evidence, finite overall
continuation accounting and measured provider performance. No HTTP endpoints,
source holds/clearances, research records, admission code or frozen artifacts were
altered. No provider/Spark/geocoder request, public release, push or PR occurred.
The principles page referenced by AGENTS could not be retrieved through the web
reader during this slice; no policy text was inferred from unrelated search hits.

The separate DTO correction ZIP8aa8d4d3a047082a41fd837d15ed3d729778c0e28c8357567a6f543983f424b1
was independently cleared with no findings. The new native browse/transport slice
is author-tested and requires its own independent review.
